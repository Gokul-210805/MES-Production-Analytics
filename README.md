# MES Production Analytics Dashboard

## Project Overview

This project analyzes manufacturing production data from a Manufacturing Execution System (MES) environment using Microsoft Excel, PostgreSQL, and Power BI.

The dashboard focuses on production performance, downtime, quality, and machine-level analysis.

## Tools Used

- Microsoft Excel
- PostgreSQL
- Power BI
- DAX

## Analysis

- Analyzed production performance against planned quantities.
- Analyzed machine-level production performance.
- Analyzed production downtime and downtime reasons.
- Analyzed defect and quality-related data.
- Compared production performance across shifts, lines, and machines.
- Used PostgreSQL for data extraction and analysis.
- Used Excel for data preparation and validation.
- Used Power BI to create interactive dashboards and visualizations.

## Dashboard Features

- Production Performance Analysis
- Downtime Analysis
- Quality Analysis
- Machine-Level Analysis
- Production vs Plan
- Defect Analysis
- Interactive Filters and Slicers
- Drill-Down Analysis

## Files

- `MES_Production_Analytics.pbix` — Power BI dashboard
- `MES_Production_Analytics.xlsx` — MES production dataset
- `mes_production_analysis.sql` — PostgreSQL analysis queries
